# hand-draw

项目名称：AI 隔空手势绘图系统 v2.0

这是一个基于 MediaPipe Hands 和 Canvas API 构建的实时网页端交互系统。利用 AI 视觉算法，让用户无需触碰屏幕，仅通过摄像头捕捉手势即可在空中绘画创作。

## 核心功能

- 🖐️ 手掌控制：张开手掌呼出/隐藏功能面板（防抖 + 冷却，杜绝误触）。
- 👆 虚拟选色：食指悬停于按钮上方约 1.5 秒（带进度环提示）即可切换功能。
- 👌 捏合书写：拇指与食指捏合即可在屏幕上留下笔迹，支持双手同时绘画。
- ☝️...☝️ 双指缩放：双手食指距离实时缩放画布（0.4x ~ 5x）。
- ✌️ 雪花消散：剪刀手手势让画作化作雪花缓缓飘落消失。

## v2.0 新增 / 优化

### 识别精度与灵敏度
- 手势判定从「y 坐标比较」升级为「关节夹角判定」，对手型、朝向（侧手/倒立/倾斜）更鲁棒。
- 捏合阈值按手部尺寸动态计算（手远手近都能准确触发）。
- 手势防抖锁存：进入/退出需要连续 N 帧，消除单帧抖动造成的误触发与断线。
- 绘画点位 EMA 平滑 + 中点贝塞尔曲线，线条顺滑无锯齿。
- 菜单冷却改为时间戳（毫秒）计算，不受帧率波动影响。
- 统一屏幕坐标系（画布内镜像视频），修复旧版菜单悬停命中的坐标错位问题。
- 三档灵敏度（灵敏 / 标准 / 平滑），可在功能页随时切换。

### 新增功能
- 撤销 / 重做（最多 40 步）、一键清屏。
- 5 种笔刷：笔、荧光笔（半透明）、喷枪（散点）、彩虹笔（渐变）、橡皮（自动分段断开）。
- 8 种颜色 + 自定义取色器。
- 导出画作为 PNG 图片。
- 背景切换：视频 / 白纸 / 黑板 / 透明（带网格辅助线）。
- 画布锁定（防误触）、缩放复位、骨架显示开关。
- 双手同时捏合 → 双手同时绘画。
- 操作音效反馈、HUD 实时状态栏（工具/颜色/粗细/缩放/背景/灵敏度/锁定状态）。

## 如何运行

1. 使用 Chrome、Edge 或 Safari 浏览器。
2. 页面必须通过 **HTTPS** 协议访问（如 GitHub Pages、本地 HTTPS 服务），否则浏览器禁止开启摄像头。
3. 保持光线充足，让摄像头完整看到双手。
4. 首次打开会弹出操作指南，可随时通过功能页中的功能使用。
